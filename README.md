# NGINX SSL Proxy (Proxy Protocol) – Home Assistant app repository

Home Assistant app repository for an NGINX SSL/TLS proxy with an optional separate proxy protocol port and mTLS support.
Forked from [home-assistant/apps-example](https://github.com/home-assistant/apps-example).

Apps documentation: <https://developers.home-assistant.io/docs/apps>
